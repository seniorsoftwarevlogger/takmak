# Проверенная вертикальная TFT-версия — 13 октября 2026

`takmak_tft_left_bench.uf2` — точная копия прошивки, залитой на тестовую SuperMini nRF52840 (`nice_nano_v2`, USB serial `71AB9D85A511C2EF`). Пользователь подтвердил вертикальное изображение и переключение всех трёх страниц замыканием 008–GND.

- TFT ST7789 76×284: CLK→113, DIN→010, CS→009, DC→031, RES→029; VCC→3.3 V, GND→GND, BL→GND.
- Начальная страница — топография. Нажатие: Топография → Статус → Управление → Топография.
- Роль — левая центральная половинка. Локальная матрица отключена из-за пересечения её GPIO с экраном. Это прошивка макетки, не готовой клавиатуры.
- Удержание кнопки, физическое нажатие энкодера и подключение правой половинки отдельно не проверены.
- Для возврата: на тестовой плате дважды кратко замкнуть RST–GND и скопировать этот UF2 на диск NICENANO. Рабочую клавиатуру этой тестовой сборкой не прошивать.

Исходники и закреплённые зависимости находятся в том же Git-коммите. Полная левая сборка с другой проводкой собрана, но физически не проверена; её UF2 в этот проверенный checkpoint не включён.
