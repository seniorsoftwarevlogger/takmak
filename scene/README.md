# Takmak scene

Первая локальная интерактивная сцена для выбора ракурса будущего сайта. Два исполнения: белое низкопрофильное с оранжевыми крутилками и чёрное стандартное. Можно переключать исполнение или показать оба. Интерфейс оформлен на чистом белом фоне: нейтральная серая типографика, тонкие разделители, сдержанные элементы управления. Оранжевый акцент оставлен крутилкам и индикаторам фокуса.

## Запуск

Из этого каталога:

```sh
npm ci
npm run dev
```

Адрес по умолчанию: http://127.0.0.1:5173. Если порт занят, Vite напечатает другой адрес. Зависимости проверены с Node 22.17.0. Сцена работает локально; публикация не выполнялась. После установки для просмотра не нужны внешние CDN или шрифты.

Для production-сборки: `npm run build`. Результат находится в `dist`; обслуживать его HTTP-сервером, не открывать HTML через `file://`.

## Управление

- Перетаскивание сцены вращает камеру, колёсико приближает и отдаляет, правая кнопка перемещает цель камеры. На сенсорном экране — жесты OrbitControls.
- «Левая» / «Правая» выбирает половинку для настройки разворота, наклона и крена. Расстояние между половинками и высота левой регулируются отдельно.
- Положения половинок общие для двух профилей; это позволяет сравнивать их в одной композиции.
- «¾», «Сверху», «Спереди» устанавливают камеру и вписывают видимую сборку. На узком экране кнопка фронтального вида скрыта.
- «Зафиксировать ракурс» сохраняет положение камеры, профиль и параметры половинок в localStorage и скачивает `takmak-<profile>-pose.json`.
- «Мой ракурс» восстанавливает сохранённую композицию. Она также восстанавливается при перезагрузке. «Сбросить» возвращает начальную композицию без удаления сохранённой.
- PNG экспортирует текущий холст с прозрачным фоном. Панель управления в PNG не попадает.

Передай сохранённый JSON для следующей итерации — там есть точные значения ракурса. Локальное сохранение привязано к браузеру и адресу сервера; скачанный файл остаётся переносимым.

## Геометрия и происхождение

`public/models` содержит 11 GLB, заново полученных из предоставленных STEP в `../3d models/step`, а не изменённые исходники. В каждом GLB одна геометрия тела вместо сотен отдельных CAD-граней. Суммарно 73 494 треугольника для всех альтернативных деталей корпуса и крутилок.

`manifest.json` содержит контрольные суммы STEP, исходные габариты и пути. Координаты GLB — метры; сцена и её параметры работают в миллиметрах. Низкие верхние части сдвинуты на −150 мм по исходной оси Y, чтобы совместить их с нижними частями. Для низкопрофильной сборки нижние части вместе с reset-кнопками подняты на 2 мм: верх дна в STEP находится на Z=−4 мм, а низ верхней части — на Z=−2 мм. Это устраняет зазор в сцене. Для стандартного профиля сдвиг равен нулю. Нижние части и reset-кнопки сохраняют взаимные координаты CAD.

`layout.json` получен из замкнутых контуров отверстий под свитчи в STEP Regular Top. Для согласованной комплектации используются 30 клавиш слева и 37 справа плюс один энкодер на каждой половинке. Левая длинная клавиша и правые отдельные клавиша/энкодер выбраны по фото и уточнениям владельца. Координаты этих альтернативных посадок зафиксированы в скрипте извлечения. Это число отображаемых клавиш, а не BOM или количество позиций firmware transform.

Пересоздание геометрии и проверка:

```sh
npm run assets
npm run check
npm run build
```

Генератор использует occt-import-js/OpenCascade, а извлечение контуров — Python 3 без сторонних библиотек. Исходные STEP не изменяются.

## Границы первой итерации

- Кейкапы — процедурные визуальные приближения MBK и Cherry profile; точные CAD-модели не предоставлены. Подписи ориентируются на фото, но японские сублегенды не воспроизведены.
- Свитчи представлены упрощёнными видимыми корпусами. Это не точные CAD-модели Kailh MX/Choc.
- Экран в стандартной сборке — иллюстрация OLED, включая условное содержимое. На низкопрофильной оставлено тёмное окно, как на фото; наличие модуля в этой половинке пока не подтверждено.
- PCB, аккумуляторы, проводка, крепёж и сам внешний донгл не включены. Explode view внутренней электроники не реализован.
- Геометрическое вписывание кейкапов и крутилок предназначено для визуализации; производственная проверка посадки и зазоров не проводилась.
- Последняя изготовленная плата — 3.0, проект 3.1 ещё не изготовлен. Сцена не заявляет проверенную совместимость корпуса с 3.1.

## Проверка

Проверены переключение обоих профилей и их совместный показ, поворот камеры мышью, масштаб, независимость настроек половинок, скачивание JSON и PNG, сброс и восстановление ракурса, сохранение после перезагрузки. Автоматическая проверка сверяет хеши STEP, структуру и конечность координат GLB, габариты и уникальность посадок клавиш. Production-сборка проходит.

Исходники интерфейса: `src/main.js`, `src/style.css`, `index.html`. Скрипты подготовки: `scripts/prepare-assets.cjs`, `scripts/extract-layout.py`. Внешние модели свитчей не включены в сцену. Условия использования исходной аппаратуры остаются указанными в основном README репозитория.

## Ракурсы и топографический рисунок

Кнопка «Ракурсы 06» открывает сетку сравнения. Первые два варианта загружаются из предоставленных автором JSON (`assets/poses/user-01.json` и `user-02.json`); второй — предпочтение автора. Четыре дополнительных варианта задаются в `loadPoseOptions()` на основе второго. Карточка переносит положения половинок и направление камеры в основную сцену, затем вписывает клавиатуру в текущий размер окна; сохранение в браузер происходит только по кнопке «Зафиксировать ракурс». Закрытие галереи сохраняет предыдущее положение сцены.

Превью рендерятся последовательно одним WebGL-рендерером при одинаковых свете, размере 720×480 и увеличении 1,3× для удобства сравнения. Увеличение относится только к карточкам и сетке PNG; координаты камер в исходных JSON не меняются. Сетку можно скачать кнопкой в галерее. Прямая ссылка: `http://127.0.0.1:5173/?gallery=1`.

Исходный рисунок автора сохранён без изменений в `assets/decoration/takmak-silkscreen.dxf`. Скрипт `python3 scripts/extract-decoration.py` преобразует его 43 плоских SPLINE и 13 LINE в SVG, с 24 отсчётами на ненулевой узловой интервал сплайна. `public/decoration/takmak-full.svg` сохраняет все эти объекты; `takmak-contours.svg` содержит только кривые для оформления сайта. Источник, хеш и границы записаны в `source.json`. Рисунок использован как лёгкий фон сцены и иллюстрация истории названия в галерее. PCB и исходный DXF не редактировались.

## Выбранная композиция и парение

Основной ракурс — второй JSON автора (`user-02.json`). Он загружается по умолчанию, используется кнопками сброса и «¾», с вписыванием под размер окна. Новые сохранения используют ключ localStorage `takmak.scene.pose.v2`; прежние сохранения v1 не удаляются.

Лёгкое парение добавляет каждой половинке вертикальное отклонение до ±1,6 мм и покачивание до 0,35° с периодами 7,5 и 9 секунд. Движение не меняет исходные параметры ракурса и не накапливает смещение. Выключатель «Лёгкое парение» возвращает точную базовую позу; при prefers-reduced-motion движение выключено по умолчанию. Галерея остаётся статичной для сравнения. При скрытой вкладке и открытых диалогах анимация приостанавливается.
